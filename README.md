. Summarize the project and what problem it was solving.

My Grocery Tracker project was created to help a grocery store keep track of items purchased by customers. The program reads grocery items from an input file and counts how many times each item appears. It can also search for a specific item and display how often it was purchased. This program helps make tracking grocery purchases easier and reduces the need to count items manually.

2. What did you do particularly well?

I think I did well with organizing my code and making sure the program worked correctly. I used a map to store grocery items and their purchase frequencies, which made it easier to find and count items. I also added comments to explain different parts of my code. I was able to work through problems in Visual Studio and test my program until it worked as expected.

3. Where could you enhance your code? How would these improvements make your code more efficient, secure, and so on?

One area I could improve is adding better error handling when opening and reading the input file. For example, the program could display a helpful message if the file is missing or cannot be opened. I could also improve input validation to prevent problems when a user enters an item incorrectly. These changes would make the program more reliable and easier to use. I could also organize some of the functions further to make the code easier to update in the future.

4. Which pieces of the code did you find most challenging to write, and how did you overcome this? What tools or resources are you adding to your support network?

One of the most challenging parts was getting the program to read the input file, store the grocery items, and search for items correctly. I had to understand how maps work in C++ and how to connect the different functions. I overcame these challenges by reviewing my code, testing it in Visual Studio, and getting help understanding what needed to be changed. In the future, I plan to continue using course materials, C++ documentation, practice exercises, and debugging tools to improve my programming skills.

5. What skills from this project will be particularly transferable to other projects or course work?

The skills I learned from this project will help me with future programming assignments. I practiced using functions, maps, loops, file input, and conditional statements. I also learned the importance of testing code and fixing errors. These skills can be used in other programs that need to organize information, process data, or allow users to search for specific information.

6. How did you make this program maintainable, readable, and adaptable?

I made my program easier to maintain by using comments and separating tasks into functions. For example, the program uses functions to load grocery items and search for specific items. This organization makes the code easier to understand and helps me make changes without rewriting the entire program. Using a map also makes the program adaptable because it can keep track of different grocery items and their purchase counts. If I continue improving the program, I can add features such as sorting items, displaying additional reports, or handling file errors more effectively.
